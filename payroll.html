Reconciliation
Recorded receipts use payment-received dates. Budgeted receipts use each payment’s assigned month. Both include collected sales tax, paid extensions and unsigned paid invoices, and exclude test charges. Planning exclusions do not change recorded receipts. Checking deposits and transfers are excluded from revenue. The monthly mover total uses all logged hours. Project budgets use logged hours for each job where available and a planning estimate otherwise. Truck uses posted job-tagged Truck & Gas charges, with the planning fallback when none are tagged. Warehouse is a monthly planning allowance. Tax set-aside reuses the Tax Report's B&O + sales-tax method (not CPA-certified — see TAX_METHODOLOGY.md). "Jasmine keep (actual net)" is the existing planning allocation result, including estimated costs, not accounting profit; "Project keep estimate before shared work (target)" is a benchmark line only — the two are never blended, and the target is capped at actual profit so it can never exceed what the month really made. Inventory (shopping budget) is derived, never entered: whatever is left after costs and the keep target. A month with unreconciled revenue is flagged, not presented as final. Viewing this page never changes a stored record — only the Manual Override controls write anything.
