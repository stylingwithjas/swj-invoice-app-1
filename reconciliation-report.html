Reconciliation Report
What this is
Read-only. This page never writes anything — it only reads invoices already in the database and reports where the printed math doesn't add up. Loading or re-running it cannot change a stored record, a total, a signature, or a payment. It does not call Stripe; for paid invoices on the list, cross-check the stored paid amount against Stripe yourself.
  • Checks every invoice (proposals, signed, paid — test, duplicate-named, versioned, and $0/near-$0 records included, labeled, never silently dropped) against four checks: sum of lines = printed subtotal; printed tax = rate × the taxable base the invoice claims; printed subtotal + printed tax = printed grand total; printed extension rate = pretax subtotal ÷ 3 (where printed).
  • "Printed" means exactly what the client's PDF would show — the same formulas tax-report.html already uses (price-led back-out for old invoices, the stored override fields for new ones), copied here read-only so this report can never drift from, or accidentally change, the Tax Report.
  • Any difference of one cent or more counts as a failure. A missing or unparseable field is listed as "missing X," never guessed or defaulted to $0.
  • Status (proposal / signed / paid) is read directly off the stored paid/signed flags — paid wins over signed wins over proposal — nothing is reinterpreted beyond that.
